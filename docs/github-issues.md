# GitHub Issues

This repository uses its own GitHub Issues backlog at:

- `https://github.com/metazen11/autonomous-agents/issues`

## Workflow Labels

- `autonomous:ready`
- `autonomous:blocked`
- `autonomous:human`
- `autonomous:in-progress`
- `autonomous:follow-up`

## Intended Usage

- shared backlog and public implementation tracking use GitHub Issues
- local or offline execution can still use `todo.json`
- progress comments should point to artifacts and verification evidence
- automation improvements that are not implemented immediately should become `autonomous:follow-up` issues
