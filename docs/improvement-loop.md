# Improvement Loop

The system is intended to improve through a promotion ladder:

1. run artifact
2. pattern candidate
3. lesson or playbook
4. script, adapter, or prompt-pack change

## What Gets Promoted

- repeated successful command sequences
- repeated retries caused by missing preflight checks
- stable verification chains
- repeated human decisions that can be turned into rules

## What Does Not

- one-off debugging commands
- noisy or environment-specific failures without repeated evidence
- raw log dumps
